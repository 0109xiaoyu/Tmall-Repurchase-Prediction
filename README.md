# 天猫用户复购预测与精准营销策略研究

> 基于百万级用户行为日志的多维特征工程、LightGBM分类建模与SHAP解释性分析 —— 从数据清洗、特征构建、不平衡样本处理到模型可解释性与业务落地的完整数据挖掘闭环

随着电商平台的快速发展，获取新客的成本远高于维护老客，如何识别高概率复购用户，实现精细化营销，成为平台和商家降本增效的核心诉求。本项目基于天猫平台真实的用户行为日志（包含点击、加购、购买、收藏等行为）与用户画像信息，构建了一套完整的数据挖掘框架。通过“数据处理 → 探索性分析 → 多维特征工程 → 不平衡样本建模 → 可解释性与业务赋能”五个递进环节，实现用户复购概率的精准预测，并为业务部门提供高潜用户名单与营销策略建议。

| 问题 | 目标 | 方法 |
|:---:|:---|:---|
| Q1 | 数据清洗与探索性分析，识别基本复购规律 | 缺失值填补 + 去重 + 交叉可视化分析 |
| Q2 | 从用户、商家及交叉维度提取高维特征 | 多维聚合统计 + 独热编码 + 时间差特征 |
| Q3 | 构建并优化复购预测分类模型 | 下采样处理不平衡 + LightGBM + 早停机制 |
| Q4 | 模型可解释性分析与业务营销策略落地 | SHAP值分析 + Lift提升曲线 + 高潜名单输出 |

## 1. 数据集

| 数据类型 | 数量/说明 |

| 数据处理策略 | 行为日志数据量过大，采用 `chunksize` 分块读取与合并，防止内存溢出 |

### 1.2 核心特征说明

| 特征类型 | 内容 | 建模角色 |
|------|------|----------|

| 用户-商家交叉特征 | 用户在特定商家的交互次数、在特定商家的商品/品类/品牌交互数、在特定商家的点击/加购/购买/收藏次数、特定商家购买率、在特定商家的活跃天数 | **交叉维度特征工程** |

## 2. 数据清洗与质量控制

1. **缺失值处理**：由于电商行为数据的特殊性，缺失值通常代表“未发生该行为”。因此，将 `age_range` 缺失填补为 0，`gender` 缺失填补为 2，`brand_id` 缺失填补为 0；
2. **重复值剔除**：对用户行为日志（`user_log`）进行全局去重，避免重复记录导致特征统计量放大；
3. **字段重命名**：将行为日志中的 `seller_id` 统一重命名为 `merchant_id`，方便后续多表关联；
4. **数据类型优化**：对 `item_id`、`cat_id`、`brand_id` 转为 `int32`，`action_type` 转为 `int8`，有效降低内存占用；
5. **数据落盘**：清洗后的数据保存为 `userinfo.csv` 和 `userlog.csv`，供后续快速读取。

## 3. 探索性数据分析（EDA）

利用 Matplotlib 和 Seaborn 对正负样本及用户属性进行交叉分析：
*   **样本分布**：绘制正负样本饼图，观察复购（Label=1）与非复购（Label=0）的比例，发现样本存在明显的不平衡现象。
*   **性别与复购**：绘制柱状图，分析不同性别群体的复购率差异（发现女性用户复购倾向略高于男性）。
*   **年龄与复购**：绘制年龄区间与复购标签的交叉分布图，发现特定年龄段（如年轻群体）的购买行为更活跃。

> **结论**：用户属性对复购行为有一定影响，但行为数据（点击、加购等）具有更大的挖掘潜力。

## 4. 特征工程

将训练集与测试集合并（`matrix`），基于清洗后的行为日志，提取了 **42 维** 高阶特征：

### 4.1 用户维度特征
*   **平台活跃度**：用户在平台的总交互次数（`user_num`）、最近一次购买距离第一次的时长（`user_days`）；
*   **广度特征**：用户交互过的不同商品数（`item_num`）、品类数（`cat_num`）、品牌数（`brand_num`）、商家数（`merchant_num`）；
*   **行为漏斗**：用户点击（`uclick_num`）、加购（`uadd_num`）、购买（`ubuy_num`）、收藏（`usave_num`）的次数；
*   **转化率**：用户购买率（`user_buy_rate` = 购买次数 / 点击次数）。

### 4.2 商家维度特征
*   **流量规模**：商家被交互的总次数（`merchant_benum`）、被交互的用户数（`merchant_user`）及商品/品类/品牌数；
*   **转化漏斗**：商家被点击（`mclick_num`）、被加购（`madd_num`）、被购买（`mbuy_num`）、被收藏（`msave_num`）的次数；
*   **历史表现**：商家的历史复购次数（`merchant_rebuy`）与商家被购买率（`merchant_buy_rate`）。

### 4.3 用户-商家交叉特征（核心）
*   **交互深度**：用户在特定商家的交互次数、在特定商家的商品/品类/品牌交互数；
*   **行为偏好**：用户在特定商家的点击、加购、购买、收藏次数，以及**用户在该商家的购买率**（`user_merchant_buy_rate`）；
*   **时间窗口**：用户在该商家的最近一次购买距离第一次的时长（`user_merchant_days`）。

### 4.4 离散特征编码
*   对 `age_range` 和 `gender` 进行独热编码（One-hot Encoding），删除原始列，并填补所有缺失值（0），划分训练集（`train.csv`）与测试集（`test.csv`）。

## 5. 模型构建与评估

### 5.1 样本不平衡处理
由于复购样本占比较少，采用**下采样（Undersampling）** 策略，从 Label=0 的样本中随机抽取与 Label=1 数量相同的样本，构建 1:1 的平衡数据集。

### 5.2 标准化与划分
使用 `StandardScaler` 对 42 维特征进行标准化，并按 8:2 划分训练集与验证集（`random_state=2021`）。

### 5.3 LightGBM 模型训练与调优
*   **参数设置**：`n_estimators=1000`, `max_depth=8`, `num_leaves=25`, `colsample_bytree=0.5`, `learning_rate=0.1`；
*   **早停机制**：设置 `early_stopping_rounds=100`，监控验证集 AUC。模型在 [40] 轮达到最佳，有效防止过拟合；
*   **模型评价**：
    *   最佳验证集 AUC：**0.6838**
    *   准确率 (Precision)：**0.6403**
    *   F1 值：**0.6514**
    *   模型与标准化器已持久化保存（`lgb_model.pkl` / `scaler.pkl`），供后续推理使用。

## 6. 模型可解释性与业务赋能

### 6.1 SHAP 模型可解释性分析
引入 `shap.TreeExplainer` 对模型进行解释。绘制 **SHAP 摘要图（Summary Plot）**，分析各特征对复购预测的贡献度。
*   **结论**：用户在商家的加购次数、近期活跃天数、历史购买率等特征对预测结果影响最大。这些特征具有高度可解释性，符合电商业务的直观逻辑。

### 6.2 Lift 提升曲线与业务评估
绘制 **Lift 曲线（提升曲线）**，衡量模型在业务应用中的实际价值：
*   **业务指标**：如果营销预算只够触达 **Top 10%** 的高潜用户，模型能覆盖 **15.13%** 的复购用户，相比随机营销效率提升了 **1.51 倍**；
*   如果触达 **Top 20%** 的用户，能覆盖 **27.86%** 的复购用户，效率提升 **1.39 倍**。

### 6.3 业务落地：高潜用户名单输出
利用保存的模型与标准化器，对 `test.csv` 进行预测，筛选预测概率 **> 0.7** 的极高潜用户。
*   **输出结果**：共生成 **8124 名**高潜用户名单（`high_potential_users.csv`），包含 `user_id`, `merchant_id`, `prob`。业务部门可直接依据此名单进行定向发券、短信触达等精细化营销。

## 7. 核心结论与建议

### 结论
1. 电商用户复购行为受“用户历史活跃度”和“特定商家交互深度”双重驱动，其中**加购行为**是复购的最强前置信号；
2. 模型在保证一定泛化能力（AUC 0.68）的前提下，具备显著的**业务提效价值**，Top 10% 预测样本即可捕获超过 15% 的复购行为；
3. LightGBM 结合 SHAP 和 Lift 曲线，不仅解决了“预测”问题，更解决了“为什么预测”和“预测后怎么用”的业务痛点。

### 建议
*   **运营侧**：针对模型输出的 Top 高潜名单，倾斜营销预算，优先发放店铺优惠券；
*   **产品侧**：针对“加购但未购买”的用户，优化购物车催付机制，缩短决策链路；
*   **算法侧**：未来可引入 XGBoost 与 LightGBM 进行模型融合，或尝试 `scale_pos_weight` 参数替代下采样，保留更多负样本信息以提升 AUC。

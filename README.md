# 天猫用户复购预测与精准营销策略研究

> 基于百万级用户行为日志的多维特征工程、防数据泄露的LightGBM建模与SHAP解释性分析 —— 从数据清洗、特征构建、不平衡样本处理到模型可解释性与业务落地的完整数据挖掘闭环

随着电商平台发展，获取新客成本远高于维护老客，如何识别高概率复购用户、实现精细化营销成为降本增效的核心诉求。本项目基于天猫平台真实用户行为日志与画像信息，构建“数据处理 → 探索性分析 → 多维特征工程（防泄露） → 不平衡样本建模 → 可解释性与业务赋能”五个递进环节，实现复购概率的精准预测，并提供高潜用户名单与营销策略建议。

| 问题 | 目标 | 方法 |
|:---:|:---|:---|
| Q1 | 数据清洗与探索性分析，识别基本复购规律 | 缺失值填补 + 去重 + 交叉频数统计 |
| Q2 | 从用户、商家及交叉维度提取高维特征 | 多维聚合统计 + 独热编码 + 时间差特征 |
| Q3 | 构建防泄露的复购预测模型 | 下采样 + GroupKFold + K折交叉目标编码(OOF) |
| Q4 | 模型可解释性与业务营销策略落地 | SHAP值分析 + Lift提升曲线 + 高潜名单输出 |

## 1. 数据集

### 1.1 数据来源与规模

| 数据类型 | 数量/说明 |
|---|---|
| 训练集 (`train_format1.csv`) | 包含用户ID、商家ID及复购标签（Label 0/1） |
| 测试集 (`test_format1.csv`) | 包含用户ID、商家ID，需预测复购概率 |
| 用户画像 (`user_info_format1.csv`) | 包含年龄区间、性别等基础信息 |
| 用户行为日志 (`user_log_format1.csv`) | 百万级行为数据，包含点击、加购、购买、收藏及时间戳 |
| 数据处理策略 | 日志数据过大，采用 `chunksize` 分块读取与合并，防止内存溢出 |

### 1.2 核心特征说明

| 特征类型 | 内容 | 建模角色 |
|------|------|----------|
| 用户基础画像 | 性别、年龄区间 | 控制变量 / 独热编码输入 |
| 用户行为特征 | 交互总次数、活跃天数、不同商品/品类/品牌/商家交互数、各动作次数、购买率 | **用户维度特征** |
| 商家行为特征 | 商家被交互次数、覆盖用户数/商品数、各动作被操作次数、商家历史复购率 | **商家维度特征** |
| 用户-商家交叉特征 | 用户在特定商家的交互次数、商品/品类交互数、购买率、活跃天数 | **交叉维度特征** |

## 2. 数据清洗与质量控制

1. **缺失值处理**：缺失值通常代表“未发生该行为”。`age_range` 缺失填补为 0，`gender` 缺失填补为 2，`brand_id` 缺失填补为 0。
2. **重复值剔除**：对用户行为日志进行全局去重，避免重复记录导致特征统计量放大。
3. **字段重命名**：将 `seller_id` 统一重命名为 `merchant_id`。
4. **数据类型优化**：`item_id`、`cat_id` 等转为 `int32`，`action_type` 转为 `int8`，降低内存占用。
5. **数据落盘**：清洗后保存为 `userinfo.csv` 和 `userlog.csv`，供后续快速读取。

## 3. 探索性数据分析

基于终端输出的文本统计结果，关键发现如下：

**正负样本分布**：
*   未复购（Label=0）：**244,912** 条，占比 **93.88%**
*   复购（Label=1）：**15,952** 条，占比 **6.12%**
*   *结论*：样本存在极度不平衡现象，需在建模阶段进行针对性处理。

**性别与复购关系**：
*   未知性别（176,414人）：复购率 **6.45%**
*   男性（73,756人）：复购率 **5.38%**
*   女性（10,694人）：复购率 **5.57%**
*   *结论*：性别对复购行为影响较小，但未知性别群体的复购率反而最高。

**年龄与复购关系**：
*   年龄段 5.0（25,618人）：复购率 **7.00%**（最高）
*   年龄段 6.0（21,701人）：复购率 **6.83%**
*   年龄段 4.0（51,235人）：复购率 **6.72%**
*   *结论*：25-35岁（对应年龄段4-6）的用户群体复购意愿相对更强，是营销的重点目标。

## 4. 特征工程

将训练集与测试集合并（`matrix`），基于清洗后的行为日志，提取了 **42 维**高阶特征：

### 4.1 用户维度特征
*   **平台活跃度**：交互总次数（`user_num`）、最长活跃天数（`user_days`）
*   **广度特征**：不同商品数、品类数、品牌数、商家数
*   **行为漏斗**：点击（`uclick_num`）、加购（`uadd_num`）、购买（`ubuy_num`）、收藏（`usave_num`）次数
*   **转化率**：购买率（`user_buy_rate` = 购买次数 / 点击次数）

### 4.2 商家维度特征
*   **流量规模**：被交互总次数、被交互用户数/商品数/品类数
*   **转化漏斗**：被点击、被加购、被购买、被收藏次数
*   **历史表现**：商家历史复购率（`merchant_rebuy`）与商家被购买率（`merchant_buy_rate`）

### 4.3 用户-商家交叉特征
*   **交互深度**：用户在特定商家的交互次数、商品/品类交互数
*   **行为偏好**：在特定商家的点击/加购/购买/收藏次数、特定商家购买率
*   **时间窗口**：在特定商家的活跃天数（`user_merchant_days`）

### 4.4 🔥 防泄露机制
*   **目标编码防泄露（OOF）**：`merchant_rebuy` 特征采用 **5折交叉目标编码** 构建，验证折的商家复购率仅由训练折计算得出，彻底阻断目标泄露。
*   **测试集隔离**：测试集使用全局训练集的均值进行映射，绝不触碰测试集自身标签。
*   **离散特征编码**：对 `age_range` 和 `gender` 进行独热编码，并填补缺失值。

## 5. 模型构建与评估

### 5.1 样本不平衡处理
采用**下采样（Undersampling）** 策略，从 Label=0 中随机抽取与 Label=1 等量的样本，构建 1:1 平衡数据集。

### 5.2 🔥 防泄露训练策略
*   **GroupKFold 分组交叉验证**：按 `user_id` 分组，确保同一用户的行为只出现在训练集或验证集中，防止用户级信息泄露。
*   **折内标准化（In-Fold Standardization）**：每一折单独对训练集 `fit`，验证集 `transform`，杜绝测试集分布泄露。

### 5.3 LightGBM 模型训练与调优
*   **参数设置**：`n_estimators=1000`, `max_depth=8`, `num_leaves=25`, `colsample_bytree=0.5`, `learning_rate=0.1`
*   **早停机制**：`early_stopping_rounds=100`，监控验证集 AUC
*   **模型评价（5折交叉验证结果）**：
    *   交叉验证平均 AUC：**0.6816** (± 0.0062)
    *   交叉验证平均 F1：**0.6154** (± 0.0030)
    *   模型与标准化器已持久化保存（`lgb_model_no_leak.pkl` / `scaler_no_leak.pkl`）
    *   *注意*：修复数据泄露后，AUC 回落至真实水平（0.68），反映了模型在真实场景中的泛化能力。

## 6. 模型可解释性与业务赋能

### 6.1 SHAP 特征重要性分析
引入 `shap.TreeExplainer` 对模型进行解释。全局特征重要性排名如下：
1. **`merchant_rebuy`**（商家历史复购率）：SHAP值 **0.3700**（绝对核心驱动因子）
2. **`user_merchant_item`**（用户在特定商家的商品交互数）：0.1048
3. **`user_merchant_buy`**（用户在特定商家的购买次数）：0.0762
4. **`user_merchant_days`**（用户在特定商家的活跃天数）：0.0541
5. **`user_days`**（用户平台活跃天数）：0.0373

*   **结论**：**商家自身的历史复购率**是决定用户是否复购的最强信号，其次才是用户在特定商家的行为深度。这符合“好商家自带复购流量”的业务直觉。

### 6.2 Lift 提升曲线与业务评估
基于总体复购率基准（6.12%），计算不同营销覆盖范围下的业务价值：
*   **Top 5% 用户**：覆盖 **16.82%** 的复购用户，营销效率提升 **3.36 倍**
*   **Top 10% 用户**：覆盖 **27.70%** 的复购用户，营销效率提升 **2.77 倍**
*   **Top 20% 用户**：覆盖 **44.63%** 的复购用户，营销效率提升 **2.23 倍**
*   **Top 30% 用户**：覆盖 **56.97%** 的复购用户，营销效率提升 **1.90 倍**

*   **结论**：模型具备极高的业务价值。如果只针对 Top 5% 的高潜用户进行营销，可用 5% 的成本撬动近 17% 的复购，投入产出比极佳。

### 6.3 业务落地：高潜用户名单输出
利用保存的模型与标准化器，对测试集进行预测：
*   筛选预测概率 **> 0.7** 的极高潜用户，共生成 **16,226 名**高潜用户名单（`high_potential_no_leak.csv`）。
*   业务部门可直接依据此名单进行定向发券、短信触达等精细化营销。

## 7. 核心结论与建议

### 结论
1. 样本极度不平衡（复购率仅 6.12%），需采用下采样与分组交叉验证保证模型稳定性。
2. 防泄露处理后，模型交叉验证平均 AUC 稳定在 **0.6816**，反映了真实的泛化能力。
3. **商家历史复购率（`merchant_rebuy`）** 是复购预测的第一核心特征（SHAP值0.37），远超用户行为特征。
4. 模型具备显著的**业务提效价值**，Top 5% 预测样本即可捕获 16.82% 的复购行为，营销效率提升 **3.36 倍**。

### 建议
*   **运营侧**：优先针对模型输出的高潜名单进行资源倾斜，聚焦头部商家的高潜用户。
*   **产品侧**：针对“加购但未购买”的用户，优化购物车催付机制，缩短决策链路。
*   **算法侧**：未来可尝试 `scale_pos_weight` 参数替代下采样，保留更多负样本信息以进一步提升 AUC。
